## Объём задачи и критерии приёмки

Приоритет: высокий. Фото 1 от 10.09: bottom sheet предлагает только trial.

- Вернуть вторичную кнопку «У меня есть промокод» / «I have a promo code»
  под основным CTA в `lib/components/no_balance_widget.dart`.
- Переиспользовать существующий `PromoRedeemWidget` и серверный `redeemPromoCode`.
  Проверить аналогичный вход с dashboard, где CTA уже присутствует; согласовать
  навигацию между bottom sheets, клавиатуру и SafeArea.
- После успешного применения обновлять подтверждённое состояние доступа и
  закрывать/обновлять исходное окно. Не считать факт закрытия формы успешным
  применением и не включать звонки локально без результата сервера.
- Сверить фактическую выдачу промокода с моделью trial/Premium/подарочных
  минут. Активные подарочные минуты дают доступ к звонку и списываются через
  серверный settlement path; после активации канонический документ пользователя
  обновляется до возврата успешного результата.
- Повторное нажатие/ошибка сети не должны приводить к двойному применению;
  отмена оставляет исходный экран рабочим.

Приёмка: из окна на скриншоте можно открыть ввод кода на RU/EN, применить валидный
код, получить понятную ошибку для невалидного и вернуться после отмены. Проверить
итоговый доступ через существующий subscription gate, а не только видимость CTA.

## Результат выполнения

- В `NoBalanceWidget` возвращён локализованный вторичный CTA, который открывает
  существующий `PromoRedeemWidget`; после успешной активации обновляется
  канонический документ доступа пользователя.
- Успешная активация теперь возвращает `true`: исходное окно закрывается только
  после подтверждённого результата сервера. Отмена оставляет его открытым.
- Аналогичный CTA на student dashboard локализован для RU/EN.
- Добавлена проверка реального пользовательского пути RU/EN: CTA открывает форму,
  отмена закрывает только форму и сохраняет исходное окно.
- Review pass 1 выявил потерю success-result при альтернативном закрытии и
  переполнение на ограниченной высоте. Добавлены SafeArea/scroll и проверка
  server success на малом экране с увеличенным шрифтом.
- Review pass 2 выявил обход `PopScope` нативным drag и возможность закрытия во
  время callable. Все входы переведены на единый `showPromoRedeemSheet`: drag и

  однократный вызов и закрытие обоих окон после подтверждённого успеха.
- Review pass 3 выявил русские server-message в EN-интерфейсе. Прямой вывод
  сообщения убран: ошибки локализуются по стабильному Firebase code, включая
  `not-found`, `already-exists`, `failed-precondition` и безопасный fallback.
