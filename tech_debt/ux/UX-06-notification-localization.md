## Объём задачи и критерии приёмки

Приоритет: средний. Подтверждённый дефект: приложение на английском, а уведомление
о копировании ID — «ID аккаунта скопирован».

Причина в коде: в `profile_widget.dart:2574` и `profile_widget.dart:3970`
в `actions.showTopNotification` передаётся русская строка напрямую. Проверить оба
пути отображения профиля; исправление только одного оставит дефект во втором.

- Заменить оба сообщения локализованным значением существующего механизма
  `FFLocalizations`: RU «ID аккаунта скопирован», EN «Account ID copied».
- Провести целевой аудит всех пользовательских уведомлений приложения:
  `showTopNotification`, snackbar/toast, диалоги, ошибки форм, подтверждения
  копирования/сохранения/удаления, уведомления чатов, событий и подписок.
  Искать не только кириллицу: английская строка без RU-варианта — тот же дефект.
- Для каждой находки определить, является ли строка пользовательским UI,
  содержимым пользователя, техническим логом или текстом из backend. Имена,
  сообщения, названия событий, Email/Telegram и адреса контактов автоматически
  не переводить. Не устраивать глобальную замену всех русских литералов.
- Выбирать язык приложения в момент показа, а не язык устройства или значение,
  сохранённое при создании сервиса. Проверить смену RU → EN без перезапуска,
  включая результат асинхронной операции, начатой до переключения языка.
- Если в UI выводится серверная ошибка, использовать локализованное отображение
  известных кодов и общий переводимый fallback. Не выводить сырые exception texts.
  Удалённые push-уведомления инвентаризировать отдельно: язык получателя, fallback
  и сохранение locale требуют отдельной проверки backend, если найден дефект.
- В план реализации внести краткий реестр найденных пользовательских строк и их
  исправлений. Использовать существующую локализацию, без миграции всей системы.

Файлы: `lib/shared_pages/profile/profile_widget.dart`,
`lib/custom_code/actions/show_top_notification.dart`,
`lib/flutter_flow/internationalization.dart` и найденные call sites.

Приёмка: уведомление копирования и остальные проверенные сообщения соответствуют
RU/EN, в том числе после смены языка. В существующий profile widget test добавить
поведенческий сценарий копирования с английским locale и переключением языка;
не писать отдельный тест на каждый заменённый литерал.

## Результат выполнения

- Оба варианта профиля теперь показывают `Account ID copied`/`ID аккаунта
  скопирован` по языку приложения в момент нажатия. Поведенческий тест меняет
  RU → EN без перезапуска и проверяет фактически показанный overlay.
- Локализованы одноязычные validation/save feedback в регистрации, student и
  teacher onboarding, profile edit, edit-name/about/language/goal, review form,
  availability interval и upload picker. Технический MIME больше не виден
  пользователю и остаётся только в debug-логе.
- Raw backend exception text удалён из withdrawal, review submission и waiting
  for partner; UI использует известные status/code и локализованный fallback.
- Foreground partner push получил `bodyRu`/`bodyEn` в data и выбирает вариант по
  текущей локали при показе, а не по языку payload, созданного ранее.
- Отдельно проинвентаризирован `Unknown Caller` в системном CallKit. Это не
  feedback-текст и обычно заменяется именем пользователя; изменение фоновой
  системной локализации без гарантированно загруженной app locale не включено в
  этот UI-fix и не влияет на дефект со скриншота.
- Проверки: полный `flutter analyze --no-pub` — clean; 112 профильных Flutter
  тестов — pass; Firebase Functions `npm run lint` и 4 passive-search policy
  tests — pass; `git diff --check` — clean.
- Review pass 1 выявил вывод неизвестного backend error code и недостаточную
  проверку смены локали foreground push. Код скрыт за общим fallback; тест теперь
  ставит RU-push в очередь, переключает приложение на EN и только затем показывает.
- Review pass 2 принят с одной неблокирующей находкой: fallback имени партнёра
  мог смешивать языки в `bodyRu`/`bodyEn`. Добавлены независимые `nameRu` и
  `nameEn`; Functions lint и 5 policy tests проходят.
- Финальный review: PASS, actionable findings нет; correctness/localization/safety
  10/10. Device QA остаётся в UX-14. Backend deploy понадобится после
  объединения UX-пакета; commit/push/deploy ещё не выполнялись.
