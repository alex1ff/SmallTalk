# Task 13 — asset inventory and measured optimization

Дата: 09.09.2026. Ветка: `codex/smalltalk-v2-remediation`.

## Inventory

- `pubspec.yaml` перечисляет 43 runtime assets after Flutter font tree-shaking.
- Release web build до оптимизации содержал 3,959,858 байт в
  `build/web/assets/assets`.
- Самые тяжёлые runtime resources: `World_Map_Pinging_Animation.json`
  (405,072 B), четыре SF Pro шрифта (1,290,328 B суммарно), `logo.png`
  (195,681 B), `Confetti_Animation.json` (173,770 B), `sticker_32.png`
  (160,238 B) и три onboarding JPEG (362,206 B суммарно).
- 10 репозиторных изображений не перечислены в `pubspec.yaml` и не имеют
  статических Dart/test ссылок. Они не удалялись: dynamic Firestore/native
  references не доказаны отсутствующими.

## Applied change

Six 640×640 fallback search avatars (`orbiting_avatar_1…6.jpg`) were re-encoded
with FFmpeg JPEG quality 2. Dimensions and asset paths remain unchanged, so no
Dart or runtime contract changed.

| Resource set | Before | After | Difference |
|---|---:|---:|---:|
| Six orbiting avatars | 607,408 B | 314,614 B | −292,794 B (−48.2%) |
| Release web asset payload | 3,959,858 B | 3,667,064 B | −292,794 B (−7.4%) |

Per-file SSIM against the pre-encoding source was 0.9918–0.9923 (YUV `All`
score), with dimensions unchanged. Flutter web release build completed
without missing assets. The avatar widget test passed 3/3.

## Limits and follow-up

The local machine has no Android SDK, so `flutter build appbundle --analyze-size`
could not run. Mobile memory/decode traces and App Store thinning remain in the
final physical-device task 02. This evidence therefore claims only the
measured web asset payload reduction, not a mobile download or startup claim.
